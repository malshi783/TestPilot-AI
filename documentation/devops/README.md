# TestPilot AI

### Agentic AI-Powered Software Quality Engineering Platform

TestPilot AI is an intelligent software testing platform designed to assist software teams with requirement analysis, AI-powered test generation, test coverage analysis, automated test execution, defect analysis and quality reporting.

## Technology Stack

- Frontend: React
- Backend: Node.js and Express.js
- Database: PostgreSQL
- AI Integration: LLM API
- Test Automation: Playwright
- Version Control: Git and GitHub

## Main Modules

1. Requirement Analysis
2. AI Test Planning
3. AI Test Case Generation
4. Test Coverage Analysis
5. Automated Test Execution
6. AI Defect Analysis
7. Regression Testing
8. Quality Dashboard

Currently in the Business Analysis and Requirements Engineering phase.
